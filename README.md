# Simple E-Commerce Web Application

This is a basic front-end web application for an **E-Commerce portal** similar to Flipkart or Amazon.  
It is created using **HTML, CSS, and JavaScript only** — no backend or advanced frameworks.

---

## Project Structure
 E-Commerce-Website
├── index.html → Home page
├── products.html → Product listing page
├── about.html → About Us page
├── contact.html → Contact Us page
├── register.html → User registration form
├── login.html → Login form
└── README.md → Project documentation

---

##  Features

- Simple navigation menu (Home, Products, About Us, Contact Us)
- User registration and login with **basic JavaScript validation**
- Product list, Wishlist, Comments & Reviews sections
- Customer care and report issue options
- Clean, beginner-friendly code with **internal CSS and JS**

---

##  Technologies Used

- **HTML** — Structure of web pages  
- **CSS** — Basic internal styling  
- **JavaScript** — Simple form validation and interactivity
